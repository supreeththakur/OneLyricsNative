# OneLyrics v1.1.7 Release Notes

## 🚀 Performance Improvements
- **Smooth Playhead Scrolling:** Massively optimized the TimelineView auto-scrolling logic. The timeline no longer jitter-scrolls frame-by-frame during playback. It now smartly jumps and animates only when the playhead approaches the edges, saving significant CPU overhead and making the app feel buttery smooth. (Resolves #4)

## 🐛 Bug Fixes
- **Audio Overlap Fix:** Fixed a critical bug where returning to the Home/Projects menu while a video was playing would leave the background audio running indefinitely. Now, navigating back automatically pauses all playback. (Resolves #5)

## 🕰 Previous Features
- Separate DMG binaries for Intel and Apple Silicon Macs.
- macOS Ventura compatibility.
