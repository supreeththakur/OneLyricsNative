# OneLyrics v1.1.11 Release Notes

## ✨ New Features
- **Timeline Template Menu:** Added a highly-requested "Templates" dropdown menu directly above the timeline (right next to the "Add Text" button). 
- **Faster Workflows:** You can now instantly click on any of your saved text templates to insert them into the timeline immediately, as well as create new ones right from the timeline UI. (Resolves #11)

- None in this patch.

## 🕰 Previous Features

- Persistent export settings (automatically remembered).
- Massive UI Polish (Glassmorphism, native colors).
