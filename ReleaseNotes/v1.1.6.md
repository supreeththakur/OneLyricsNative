# OneLyrics v1.1.6 Release Notes

## 🚀 Architecture Updates
- **Separate DMG Releases:** We abandoned the "Universal Binary" (fat binary) approach because it was causing extreme bloat and performance degradation on older Intel Macs. We now build, package, and release two distinct binaries:
  - `OneLyrics-AppleSilicon.dmg` (Optimized for M1/M2/M3 chips)
  - `OneLyrics-Intel.dmg` (Optimized for legacy Intel Macs)
  (Resolves #1 and #2)

## 🐛 Bug Fixes
- **Asset Purging:** Fixed an issue where the OS was purging background media files by moving the local storage from temporary directories to `Documents/OneLyrics/Assets`.
- **macOS Ventura Compatibility:** Refactored various `onChange` modifiers to ensure full compatibility down to macOS 13.0.

## 🕰 Previous Features
- Core lyric video editing functionality.
- AI Lyrics Sync.
