# OneLyrics v1.1.9 Release Notes

## 🎨 New Features & UI Polish
- **Modernized Timeline:** Added beautiful purple-blue gradients to lyric blocks, replacing the flat blue color.
- **Dropshadows:** Added subtle dropshadows to lyric blocks to make them stand out.
- **Glassmorphic Buttons:** The "AI Sync" and "Add Text" buttons on the timeline toolbar now feature a premium glass/gradient look.
- **Native macOS Sidebar:** The Inspector Sidebar now uses the native macOS `windowBackgroundColor` instead of a dull flat gray, blending seamlessly with the operating system.
- **Persistent Export Settings:** Export settings (Format, Resolution, Bitrate, Output Path, and YouTube toggle) are now automatically saved using `@AppStorage`. You no longer need to re-enter them for every export! (Resolves #8)

## 🐛 Bug Fixes
- None in this specific patch, focused entirely on UI polishing and Quality of Life improvements.

## 🕰 Previous Features
- Separate architecture builds (Intel & Apple Silicon) for maximum performance.
- Background image fetching and online audio search tools.
- Advanced timeline with AI lyrics synchronization.
