# OneLyrics Suite v2.0.4

### New Features
- **Punjabi (Gurmukhi) Transliteration:** Added full support for translating Punjabi (Gurmukhi) lyrics into Romanized spelling (Hinglish/Punjabish aesthetics). 
- The auto-detection engine now dynamically identifies and properly transliterates mixed sentences containing English, Hindi, Kannada, AND Punjabi simultaneously!
- Updated the transliteration UI toggle to indicate Punjabi support.
