# OneLyrics v2.0.0

We are thrilled to announce the v2.0.0 release of OneLyrics!

### Major Improvements
- **Massive UI/UX Overhaul in Exporter:** 
  - Complete redesign of the exporter queue and management view.
  - New "Folder-like" grouping for dates and projects with beautifully separated containers.
  - Greatly expanded layout to make full use of screen real estate.
  - Buttons and interactive elements are now much larger, bolder, and more responsive with improved click targets.
- **Unified App Branding:** The Exporter App now correctly features the same beautiful AppIcon as the main OneLyrics app when installed or distributed.
- **Improved Layout Stability:** Resolved various layout clipping and resizing bugs that caused clipping on window resizes.

### Fixes
- Fixed an issue where the progress bar in the active exporter job would artificially expand the view width.
- Fixed alignment issues where centered items mistakenly snapped to the left edge.
- Fixed UI elements colliding due to previous rigid constraints.

Enjoy the completely refreshed, premium Exporter experience!
