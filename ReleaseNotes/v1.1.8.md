# OneLyrics v1.1.8 Release Notes

## ✨ New Features
- **Persistent Search State:** The Fetch Background Modal and Online Audio Search Modal now remember your search query and results even if you close and reopen the modal. They will only reset when you explicitly clear the search. (Resolves #7)

## 🐛 Bug Fixes
- Fixed an issue where closing the search modals would completely destroy the user's active search results, requiring them to search again.
- Confirmed closure of Issue #3 (Performance for Intel Macs) on GitHub.

## 🕰 Previous Features
- Fixed playhead lag and audio overlapping issues.
- Separate architecture builds (Intel & Apple Silicon).
