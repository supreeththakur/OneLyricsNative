# OneLyrics Suite v2.0.5

### Hotfix
- **Haryanvi/Marathi Character Support:** Fixed an issue where the regional Devanagari character `ळ` (Lla) was missing from the transliteration engine, causing it to pass through un-romanized (e.g., "HARIYAANE AAळE"). It now correctly maps to "L" (e.g., "AALE").
