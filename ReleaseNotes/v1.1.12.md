# OneLyrics v1.1.12 Release Notes

## ✨ New Features
- **Direct Template Button:** The Timeline's template option is no longer a multi-step dropdown menu! It is now a single direct action button. One click instantly inserts your primary text template into the timeline for ultra-fast workflows. (Resolves #13)

## 🐛 Bug Fixes
- **Timeline Scrolling Fixed:** Resolved an issue where zooming the timeline could cause the view to accidentally scroll vertically and get stuck. The timeline is now strictly constrained to horizontal scrolling for a solid editing experience. (Resolves #12)

## 🕰 Previous Features
- macOS Menu Bar Templates option.
- Persistent export settings (automatically remembered).
- Massive UI Polish (Glassmorphism, native colors).
