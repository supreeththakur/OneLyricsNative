# OneLyrics Exporter v1.0.0

Welcome to the initial standalone release of OneLyrics Exporter! 

### Features
- **Standalone App Experience:** The Exporter is now a completely distinct application, cleanly separated from the main OneLyrics interface.
- **Queue Management UI:** Beautifully crafted layout to manage all your upcoming and active exporting jobs.
- **Responsive Layouts:** Enjoy responsive resizing, bold new typographic elements, and large clickable targets for ease-of-use.
- **Unified Branding:** The Exporter comes packaged with our unified icon branding.

Download the DMG corresponding to your machine (Apple Silicon or Intel) and enjoy a smoother workflow!
