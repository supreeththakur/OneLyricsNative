# OneLyrics Suite v2.0.1

This is a minor patch release to address a critical bug in the transliteration engine.

### Bug Fixes
- **Devanagari Nukta Transliteration:** Completely fixed a rendering bug where Devanagari characters containing the Nukta modifier (e.g. `क़`, `ख़`, `ज़`) were failing to be properly translated into Roman/English script. The engine now operates securely at the Unicode scalar level, ensuring 100% accurate conversion for mixed and modified scripts without leaving straggling Hindi characters in your English text.
